# Housing Price Analysis | Data Cleaning & Preprocessing

## 📌 Project Overview

This project focuses on data cleaning, preprocessing, and housing price prediction using an Excel dataset. Each stage is documented in a separate worksheet to demonstrate the data preparation process from the original dataset to model evaluation.

## 🎯 Project Objectives

- Explore the original dataset and identify data quality issues.
- Detect duplicate records.
- Clean and preprocess data.
- Encode categorical variables.
- Identify and analyze outliers using the Interquartile Range (IQR) method.
- Split the dataset into training and testing sets.
- Compare actual and predicted housing prices.
- Evaluate model performance using regression metrics.

## 📂 Project Structure

The Excel workbook contains the following worksheets:

| Worksheet | Description |
|---|---|
| `housing- Dataset` | Original housing dataset |
| `cleaning` | Data cleaning and categorical encoding |
| `outliar droping(1)` | Outlier calculations and analysis |
| `outliar droping(2)` | Dataset after outlier removal |
| `outliar droping(3)` | Additional outlier-processing results |
| `test-train` | Training and testing data split |
| `train` | Training data and model preparation |
| `test` | Predictions and model evaluation |

## 📊 Model Evaluation

The project uses the following regression metrics to evaluate housing price predictions:

- **MAE (Mean Absolute Error):** Measures the average absolute prediction error.
- **MSE (Mean Squared Error):** Measures the average squared prediction error.
- **RMSE (Root Mean Squared Error):** Measures prediction error in the target variable's units.
- **R² (Coefficient of Determination):** Measures how well the model explains variation in housing prices.
